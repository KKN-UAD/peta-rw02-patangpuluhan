cara pakai file qgis peta rw 02

buka file Peta_RW02_Patangpuluhan.qgs pakai qgis (versi 3 ke atas). semua datanya ada di peta_rw02.gpkg, jadi file itu jangan dipisah atau dihapus ya.

isinya ada titik fasilitas, batas rw 02, batas kelurahan, jalan, sungai, bangunan, sama citra satelit. citra satelitnya butuh internet biar muncul.

kalau mau ubah titik:
klik kanan layer titik fasilitas terus pilih toggle editing (yang ikon pensil). mau geser titik pakai vertex tool, mau nambah titik pakai add point feature terus isi nama sama kategorinya. kalau udah jangan lupa save layer edits.

kategorinya harus salah satu dari ini biar warnanya kebaca: tempat ibadah, kesehatan, pendidikan, pemerintahan, ekonomi, keamanan, kebersihan, lainnya. tulisnya pakai huruf depan besar kayak di data yang udah ada.

kalau mau nambah foto, taruh fotonya di folder foto terus di kolom foto isi foto/namafile.jpg

kalau mau ubah garis batas rw juga sama caranya, toggle editing di layer batas rw 02 terus geser titik-titik garisnya pakai vertex tool.

habis diedit, save terus tutup qgisnya. abis itu klik 2x file kirim_update.bat yang ada di folder qgis. udah, gak perlu login apa-apa. tunggu aja jendelanya, sekitar 3 menit peta online udah berubah, terus sekitar 5 menit banner pdf 75x45 nya otomatis kedownload ke folder banner.

kalau foto baru, taruh aja di folder foto, nanti ikut kekirim sendiri.

file token.txt jangan dihapus dan jangan disebar ke orang lain ya, itu kunci buat ngirim ke github.

nomor titiknya nanti ngurut sendiri, gak usah diisi manual.
